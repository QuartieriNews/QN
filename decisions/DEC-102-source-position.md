# DEC-102 — Position on sources and collection

Status: DECIDED (release 1.4.2)
Superseded in part by DEC-105 — see DEC-105 for current policy on naming the people
a news item is about. This entry's own rules are unaffected.
Exception for `tools/sources-study/handoff_data/` (per-item inventories without source
text kept in the repository): see DEC-109. Pointer added 16 October 2026 on the owner's
authorisation.

Rule: manual URL collection by a person, 1–2×/week, ~month ahead; no authenticated
automation; extraction via third-party service on those URLs; every item credits its
organiser and links back; source data never redistributed as a dataset; removal
requests honoured via the published contact address. Verbatim text: spec v2.5,
Part I §8 (from docs/PROJECT_HANDOVER.md §2.16).

Consequence inside this repository: raw sampled source data (organiser names,
descriptions) is not committed here — see DEC-104.

Decided by: Owner · Date: August 2026 (release 1.4.2).
